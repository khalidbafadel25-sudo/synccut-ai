SyncCut AI — ملفات الموقع الجاهزة للنشر
تطوير: خالد بافضل

هذه نسخة واجهة موقع عربية مناسبة للجوال، ويمكن رفعها إلى استضافة صفحات ثابتة مجانية.

طريقة النشر المجاني من الجوال (GitHub Pages):
1) أنشئ حسابًا في GitHub إن لم يكن لديك حساب.
2) أنشئ مستودعًا جديدًا باسم synccut-ai واجعله Public.
3) ارفع الملفات الستة الموجودة بجانب هذا الملف إلى جذر المستودع، وليس داخل مجلد فرعي.
4) افتح Settings ثم Pages.
5) اختر Deploy from a branch، ثم main و /(root)، ثم Save.
6) انتظر حتى يظهر رابط الموقع في صفحة Pages وافتحه من Chrome على أندرويد.
7) لتثبيته، من قائمة Chrome اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق» إن ظهرت.

الوظائف التي تعمل في الواجهة بدون خادم:
- فتح الموقع من الجوال.
- اختيار ملفات الفيديو والصوت ومعاينة المقاطع.
- التنقل بين المقاطع وتعديل فلاتر المعاينة.
- واجهة PWA قابلة للإضافة إلى الشاشة الرئيسية عند النشر عبر HTTPS.

مهم:
- تصدير الفيديو النهائي MP4 وتحليل المشاهد والصمت يحتاج نشر خادم backend/main.py على استضافة تدعم Python وFFmpeg، ثم ربطه من داخل الموقع بزر «ربط الخادم».
- بعض الأدوات المعروضة مثل عزل الصوت ومزامنة الشفاه ليست منفذة بعد كنماذج ذكاء اصطناعي كاملة.
- لا توجد رسوم على استضافة GitHub Pages للصفحات الثابتة العامة، لكن قد تتغير شروط الخدمات المجانية.
